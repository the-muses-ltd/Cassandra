---
title: Data Analysis
tagline: Spreadsheets, statistics, SQL and Python — the working analyst's toolkit, in the order that gets you employable fastest.
audience: Beginners aiming at analyst roles, and anyone whose current job would improve if they could actually use data.
outcome: The four core analyst skills, proven by public analyses of real datasets.
effort: 6–10 months part-time
order: 3
stages:
  - title: Spreadsheets first
    description: Most of the world's analysis happens in a spreadsheet, and it is the fastest route to being useful at work. Learn it properly — formulas, references, charts, pivot tables. Google Sheets and LibreOffice Calc are free and everything here transfers.
    resources: [gcfglobal-excel]
    checkpoint: Take a public dataset you care about and answer three questions about it in a spreadsheet, with a chart for each.
  - title: The statistics that matter
    description: Averages, distributions, correlation and significance — the ideas that stop you from fooling yourself with data. Khan Academy's practice-based approach makes them stick.
    resources: [khan-academy-statistics]
    checkpoint: Write a one-page plain-language explanation of a statistical claim from the news — what it says, and whether the data supports it.
  - title: SQL
    description: Real data lives in databases, and SQL is how every analyst gets it out. Two free interactive tracks — do SQLBolt for speed, Khan Academy for depth.
    resources: [sqlbolt, khan-academy-sql]
    checkpoint: Write ten queries against a practice database, from simple filters to multi-table joins with aggregation, and save them in a public repository.
  - title: Python for data
    description: Python takes over where spreadsheets strain — bigger data, repeatable analysis, better charts. freeCodeCamp teaches the pandas toolkit; Kaggle gives you hosted notebooks so there is nothing to install.
    resources: [fcc-data-analysis, kaggle-learn]
    checkpoint: Publish one notebook on Kaggle analysing a dataset of your choice, with your reasoning written between the code cells.
  - title: A public portfolio
    description: Analysts are hired on evidence of judgement. Turn your best work into public write-ups — the dataset, the question, the method, the honest caveats — hosted for free.
    resources: [kaggle-learn, github-pages]
    checkpoint: Two complete analyses published (Kaggle or GitHub Pages), each with a write-up a non-technical reader could follow, linked from one page with your contact details.
---
