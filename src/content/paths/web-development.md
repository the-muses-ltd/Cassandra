---
title: Become a Web Developer
tagline: From your first HTML tag to a live portfolio that can get you hired.
audience: Complete beginners. No prior experience, no paid software — just a computer and a connection.
outcome: Several real projects live on the open web, a public GitHub profile, and the skills for junior front-end work or freelancing.
effort: 6–12 months part-time
order: 1
stages:
  - title: Understand the web and set up your tools
    description: Before writing serious code, learn what actually happens when a browser loads a page, and set up a real development environment — editor, browser tools and Git. The Odin Project's Foundations opening sections walk through this better than anything else.
    resources: [odin-foundations, mdn-learn-web]
    checkpoint: Explain to someone (or in a short written note) what happens between typing a URL and seeing a page. Have your editor and Git installed and a GitHub account created.
  - title: HTML and CSS
    description: Structure and style are the trade's foundation. Build in the browser with freeCodeCamp for instant feedback, and use MDN as the reference you return to for the rest of your career.
    resources: [fcc-responsive-web-design, mdn-learn-web]
    checkpoint: Build a personal page about yourself or something you love — written by hand, no templates — and push it to GitHub.
  - title: JavaScript
    description: JavaScript makes pages interactive and is the language of the entire front-end. Work through freeCodeCamp's interactive curriculum, and read Eloquent JavaScript alongside it to understand why things work, not just how.
    resources: [fcc-javascript, eloquent-javascript]
    checkpoint: Build a small interactive app from scratch — a to-do list, calculator or quiz — and put the code on GitHub with a README explaining it.
  - title: Projects and a public portfolio
    description: Employers hire proof, not promises. Complete the substantial projects in Odin's curriculum, then host everything for free so anyone can see your work with one click.
    resources: [odin-foundations, github-pages]
    checkpoint: Three projects live on GitHub Pages, linked from a simple portfolio page with your contact details.
  - title: Go deeper — full stack
    description: With the foundations proven, follow Odin's Full Stack JavaScript path — React, Node.js and databases — building bigger projects as you go. From here you are ready to apply for junior roles and freelance work.
    resources: [odin-full-stack-javascript]
    checkpoint: One full-stack application deployed and linked in your portfolio, plus your first contribution (however small) to an open-source project.
---
